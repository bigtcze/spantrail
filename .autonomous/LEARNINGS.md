# Durable engineering lessons

Rules change future implementation or verification behavior. Evidence pointers identify concrete existing tests/docs, not broader support claims. FLOW owns cycle sequence; AGENTS owns tool and setup policy.

| ID | Topic | Durable rule and evidence |
|---|---|---|
| L001 | ESM instrumentation | Native ESM `node:http` did not activate the installed OTel require hook. Start SDK, then use `createRequire`; test a real SERVER span. This does not establish general ESM support. `experiments/correlation/run.js`; `experiments/correlation/server-entry.js`; `experiments/correlation/server.js`; `docs/correlation-proof.md`. |
| L002 | CLI boundaries | URL tests keep every required option exactly once and vary only URL; satisfy unrelated preflight (including fresh output path) so intended readiness boundary is reached. `experiments/capture/command-options.test.js`; `experiments/capture/command.test.js`. |
| L003 | Failure and cleanup | Preserve primary failure stage plus fixed sanitized operation labels, never raw exceptions. Cleanup failure rejects success; continue remaining cleanup attempts. Give non-timeout probes adequate cleanup budget; do not relax deadline tests. `experiments/capture/command.test.js`. |
| L004 | Lifecycle | Assert concrete failing boundary before expanding supervision; reconcile known failures before another writer. First run minimal ownership/acquisition/kill experiment. Playwright `detached:false` conflicts with negative-PGID kills; disable its signal handlers when orchestrator owns cleanup, retain own handlers through cleanup, test active/repeated signals and living parent. Cover late acquisition, falsy rejection and real emitters; bound waits and clear timers. `experiments/capture/lifecycle.test.js`; `experiments/correlation/lifecycle.test.js` (late browser acquisition, falsy rejection, repeated signal). |
| L005 | Runtime acceptance | Map every criterion to actual-runtime assertions and exact counts/relationships; reconcile integrated evidence after delegated lanes. No partial specialist completion; assert supplied fixture markers. Use disposable fixture applications for tracing/instrumentation tests. SDK positive acknowledgement precedes artifact publication and is independent of finite natural child exit; natural exit of finite app must not call `process.exit`. Check installed callback-vs-Promise contracts (`export` callback; `forceFlush`/`shutdown` may be promises). `experiments/postgres/harness.test.js`; `experiments/capture/command.test.js` (SIGINT during active pending checkout); `experiments/capture/capture.test.js` (natural exit without `process.exit`). |
| L006 | Source mapping | Unsupported/unusable mapping is unknown, not relabeled JS. Keep an external-caller/root negative control. Approved roots come from independent config/helper, not observed input. Test unmapped-after-mapped, same-line and source-less boundaries; malformed diagnostics must not become app failure. Validate map version, VLQ and schemes before permissive decode/normalization; check installed runtime `setSourceMapsSupport`/`findOrigin` availability despite inaccurate docs. `experiments/source-attribution/source.test.js`; `docs/source-attribution-proof.md`. |
| L007 | Validator boundaries | Valid ERROR status 2 is not malformed. Zero-ID negatives need otherwise consistent relationships. Test depth 63/64/65 and identity collisions across correlation/exported IDs. `experiments/viewer/model.test.js` (graph checks); `experiments/capture/capture.test.js` (valid ERROR status 2 assertion). |
| L008 | Browser wrappers | Request inspection can consume body; header iterators are single-use; inherited/non-enumerable RequestInit fields and getters require the original receiver. Verify server observations. Installed Chromium ordering allows resolved-promise microtasks during dispatch; do not assume async boundary. Playwright routing headers persist on redirects: zero delivery at redirect destinations; account for service-worker blocks and zero-delivery contexts. Subscribe before action; separately await app completion. `experiments/capture/browser-context.test.js`; `experiments/capture/browser-boundaries.test.js`. |
| L009 | HTTP, privacy, PG | Preserve native HTTP overload callbacks; validate observers with a working negative control; snapshot diagnostics at failure, not before wait. In-memory trace exporter alone leaves metrics/logs enabled: use explicit empty readers/processors and hostile-env isolation. Apply privacy allowlists on failures. PG URL authority may not be effective host: reject query delimiters or verify effective config, including SSL-file handling. See `experiments/correlation/privacy.test.js` and `experiments/postgres/harness.test.js`. |
| L010 | Negative controls | Invalid tests vary only target dimension; child/server/IPC marker proves intended boundary. Parent throw is not child failure. For privacy or cleanup claims, include a regression-detecting negative control or failure-path test. If guard sensitivity is uncertain, remove the guard in a disposable/in-memory mutation and require the negative test to fail. `experiments/capture/command.test.js`; `experiments/postgres/harness.test.js`. |
| L011 | Artifacts/resources | Use fresh owned temp fixtures; remove ignored outputs before producer→consumer gates. Apply resource limits at acquisition, not after parsing; viewer artifact reads cap at 1 MiB + 1 byte, including short/growing reads; close handles and exercise shared concurrent reads. `experiments/viewer/server.test.js`; `experiments/viewer/model.test.js`. |
| L012 | Setup and browser evidence | Timestamp sequential setup start/end, awaited decisive UI, raw logs, machine timings and tested environment/source snapshot; separate setup, launch and manual interaction. One cold observation is not a benchmark. For served modules verify MIME and actual execution, not HTTP 200. `docs/local-viewer.md`; `docs/correlation-proof.md`. |
| L013 | QA lanes | Repeated incomplete/contradictory broad QA wastes effort: narrow to a few runnable scenarios and require focused passing evidence before acceptance. FLOW governs dependency reconciliation and post-merge priority. |
| L014 | Autonomous context migration | AGENTS/FLOW repeated setup policy and FLOW/LEARNINGS repeated runtime controls; assign canonical owners to reduce duplication without weakening guards or DoD gates. Independent full-diff review preserved safety and exact-original-head CI passed; repair QA accepted corrected state, assertion-level pointers and pre-commit state updates, with 42 focused tests passing and protected-file comparisons clean. Rule: verify pointer assertions, record current PR state before commit, and distinguish historical/head-specific evidence from pending publication. |
